# IPC 调用约定

所有调用接口返回 `Task<string>` JSON，使用 `await`，调用前检查 `HasFunction`。操作需启用对应模块并通过验证。

数据和操作在 Framework 线程处理，调用方不要同步等待；接口未注册时须处理调用门异常。

## 版本与能力

`OmniToolbox.GetInfo()` 返回 `ipcVersion`、`pluginVersion`、`featuresAvailable`、`supportedEndpoints` 和 `events`。当前协议版本为 `1`；能力列表表示该版本支持的接口，具体可用性仍以调用结果为准。

## 公共返回格式

| 字段 | 含义 |
| --- | --- |
| `schemaVersion` | JSON 格式版本，当前为 `1` |
| `available` | IPC 宿主是否可用 |
| `error` | 调用错误；正常为 `null` |
| `accepted` | 操作是否受理，仅操作接口提供 |
| `operationID` | 长流程的请求 ID；拒绝时为 `null` |

`accepted=true` 表示已受理。长流程使用各自的 `GetOperation(operationID)` 查询结果，使用 `Cancel(operationID)` 取消；取消不能撤销已经发生的游戏操作。传送、交易与存取只取消当前角色的运行请求；自动雇员支持跨角色及登录期间查询和取消。

`GetOperation` 返回 `found` 和 `operation`。请求快照包含 `operationID`、`service`、`kind`、`characterContentID`、`state`、`error`、`startedAt`、`completedAt`、`resultKnown`。64 位游戏 ID 使用十进制字符串，时间使用 UTC ISO 8601。

| `state` | 含义 | `resultKnown` |
| --- | --- | --- |
| `Running` | 运行中 | `false` |
| `Succeeded` | 已确认完成 | `true` |
| `Failed` | 失败 | `true` |
| `Cancelled` | 已停止继续执行 | `true` |
| `Unconfirmed` | 已结束，结果无法确认 | `false` |

每个服务保留最近 128 次请求，插件重载后清空。状态接口中的 `operation` 是该服务最近的请求；调用方应按自己的 ID 查询。

## 变化通知

使用 `GetIpcSubscriber<string, object>` 订阅 JSON 消息。

| 通知 | 主要字段 |
| --- | --- |
| `OmniToolbox.Module.StateChanged` | `module`、`enabled`、`registered` |
| `OmniToolbox.Inventory.Changed` | `revision`、`currentCharacterContentID` |
| `OmniToolbox.Operation.Changed` | 完整请求快照 |

通知在后续 Framework 更新发送，不持久化。先订阅再查询初始状态，调用方卸载时取消订阅。

## 调用示例

`pluginInterface` 为已注入的 `IDalamudPluginInterface`。

```csharp
using System.Text.Json;
using System.Threading.Tasks;

var start = pluginInterface.GetIpcSubscriber<string, Task<string>>("OmniToolbox.Teleport.Start");
if (start.HasFunction)
{
    using var response = JsonDocument.Parse(await start.InvokeFunc("利姆萨·罗敏萨下层甲板"));
    if (response.RootElement.TryGetProperty("accepted", out var flag) && flag.GetBoolean())
    {
        var operationID = response.RootElement.GetProperty("operationID").GetString();
        var query = pluginInterface.GetIpcSubscriber<string, Task<string>>("OmniToolbox.Teleport.GetOperation");
        using var result = JsonDocument.Parse(await query.InvokeFunc(operationID));
    }
}
```
