# 自动雇员

对应模块：`AutoRetainer`。返回格式与通知见 [调用约定](调用约定.md)。

| IPC | 参数 | 返回内容 |
| --- | --- | --- |
| `OmniToolbox.AutoRetainer.GetStatus` | 无 | `canExecute`、`busy`、`dataReady`、`completedCount`、`nextVentureCompleteAt`、`currentCharacterContentID`、`state`、`currentTarget`、`completedCharacters`、`totalCharacters`、`operation` |
| `OmniToolbox.AutoRetainer.Start` | `string action` | `accepted`、`error`、`operationID` |
| `OmniToolbox.AutoRetainer.GetOperation` | `string operationID` | `found`、`operation`、`result` |
| `OmniToolbox.AutoRetainer.Cancel` | `string operationID` | `accepted`、`error`、`operationID` |

| `action` | 操作 |
| --- | --- |
| `collect` | 收取已完成探险，重复派遣原任务 |
| `withdrawGil` | 取出雇员金币 |
| `listCrystals` | 按已有阈值整组上架碎晶、水晶和晶簇，单价 999 |
| `reprice` | 按已有雇员排除、压价和价格保护规则改价 |

动作不区分大小写，最长 64 字符。一次只执行一项，不附带其他业务；没有符合条件的内容时成功结束。

受理时记录当前账号已登记且在自动雇员中勾选的角色。当前角色勾选后优先处理，其余按列表顺序执行，不要求目标勾选“自动登录”。发起角色必须已登记；跨角色需要自动登录可用。每个角色在当前地图水平 100 米内找已加载的可用传唤铃，找不到或操作失败时记录结果并继续其他角色。

正常结束后返回发起角色；取消或手动中断时停止后续操作，停留当前角色。请求期间暂停常驻自动触发和附带业务，收尾后恢复。忙碌时拒绝受理，不改写配置开关。

`dataReady=false` 时，`completedCount` 和 `nextVentureCompleteAt` 为 `null`；查询不会主动刷新游戏数据。数据就绪且没有未完成探险时，下一完成时间为 `null`。

`result.characters` 包含各角色的 `worldID`、`characterName`、`characterContentID`、`state`、`error`；`result.returnedToOrigin` 表示是否已确认返回发起角色。运行中也可查询已有进度。任一角色明确失败或返回失败，整轮为 `Failed`；否则有结果无法确认时为 `Unconfirmed`，全部确认后为 `Succeeded`。取消为 `Cancelled`，保留已完成结果。登录界面无法继续时报告失败，不无限等待。

通过 `OmniToolbox.Operation.Changed` 接收整轮变化，再按请求 ID 查询角色详情。请求快照中的 `characterContentID` 始终为发起角色；切角及登录期间仍可查询、取消同一请求。

```csharp
using System.Text.Json;
using System.Threading.Tasks;

var start = pluginInterface.GetIpcSubscriber<string, Task<string>>("OmniToolbox.AutoRetainer.Start");
if (start.HasFunction)
{
    using var response = JsonDocument.Parse(await start.InvokeFunc("collect"));
    if (response.RootElement.GetProperty("accepted").GetBoolean() &&
        response.RootElement.GetProperty("operationID").GetString() is { } operationID)
    {
        var query = pluginInterface.GetIpcSubscriber<string, Task<string>>("OmniToolbox.AutoRetainer.GetOperation");
        if (query.HasFunction)
        {
            using var progress = JsonDocument.Parse(await query.InvokeFunc(operationID));
        }
        // 跨角色或登录期间仍可使用同一 ID。
        var cancel = pluginInterface.GetIpcSubscriber<string, Task<string>>("OmniToolbox.AutoRetainer.Cancel");
        if (cancel.HasFunction)
            await cancel.InvokeFunc(operationID);
    }
}
```
