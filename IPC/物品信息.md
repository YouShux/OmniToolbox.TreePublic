# 物品信息

返回格式与异步调用约定见 [调用约定](调用约定.md)。

| IPC | 参数 | 返回内容 |
| --- | --- | --- |
| `OmniToolbox.UI.OpenItemInformation` | `uint itemID` | `accepted`、`itemID` |

`itemID` 使用基础物品 ID，不含 HQ 偏移。ID 为 `0` 或不在当前客户端物品目录中时，返回 `accepted=false`、`error="invalid_item_id"`，保留当前物品。

需宿主与窗口服务就绪并通过宿主访问检查，不依赖单独的功能模块开关。复用现有窗口并展开、置前，主窗口无需打开；重复调用会重新选择物品并将购买数量重置为 `1`，保留窗口尺寸与位置。

`accepted=true` 表示已设置窗口打开请求，行情与来源可能仍在加载。这是即时请求，不返回 `operationID`。

```csharp
var open = pluginInterface.GetIpcSubscriber<uint, Task<string>>(
    "OmniToolbox.UI.OpenItemInformation");
if (open.HasFunction)
{
    var response = await open.InvokeFunc(40105U);
}
```

完整在线模块示例见 [OnlineItemInformationExample.cs](https://github.com/YouShux/OmniToolbox.TreeHouseOnline/blob/main/Examples/OnlineItemInformationExample.cs)，包含托管任务、返回值检查和重载异常处理。
